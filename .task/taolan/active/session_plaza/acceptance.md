# 验收

- 作者公开后，另一个登录用户可从广场访问会话、过程和文件。
- 非作者不可改变公开状态。
- 访客编辑不改变原会话，保存后在自己的作品库可再次编辑和下载。
- 原公开撤回后新访问/临时预览被拒绝；已保存个人作品仍可使用。
- 未登录访问与跨账号读取个人作品均被拒绝。
