# 范围

本仓库实现；全部已登录用户可以浏览公开会话聊天、工具、子 Agent 和产物。仅会话创建者可公开/撤回。访客使用自己独立的编辑副本，只能保存到自己的作品、再次编辑和下载，不能应用回原工作区。原作者撤回公开不删除此前已保存的个人作品。沿用本地账号、项目配置和标准对象存储。

## 集成补充

个人作品保存成功后，用幂等结果推进 Redis 副本的作品基线，保证同一编辑窗口连续保存；原工作区 apply 权限仍被拒绝。新增两类缓存沿用两小时到期清理。广场列表使用数据库存活条件分页，不逐条全表扫描。

## 社区版列表与导航同步

采用首张运行截图封面、Markdown 对话自动补读、三个主菜单及两类作品来源说明；页面路径导航兼容已有查询链接，并保留本地账号、标准存储与未保存编辑退出保护。
