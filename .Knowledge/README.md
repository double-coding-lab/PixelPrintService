# 社区版知识库

这份知识库按社区版当前代码整理应用架构、配置、工作区、Agent 执行、预览与团队能力。阅读入口是 [索引](index.md)，机器路由是 [manifest-routing.json](manifest-routing.json)。

## 目录

- `topics/`：每个主题的核心流程、边界和下一步入口。
- `stock-docs/`：可长期引用的实现说明与存储职责。
- `matchers/`：主题自然语言关键词；与路由清单的稳定 ID 对应。

## 同步与脱敏约定

1. 同步功能语义，按社区版的标准账号、MySQL、Redis、本地/S3 存储和本机预览重写接入方式；不能只替换产品名而保留不存在的能力。
2. 配置只引用 `project.config.example.json` 和代码契约，真实项目配置、模型密钥、Cookie、授权头、加密材料和对象存储凭据不进入知识库。
3. 不复制内部域名或 IP、镜像仓库、人员账号、绝对本机目录、真实设计稿链接，以及工作区、会话、轮次和排查编号等运行数据。
4. 不搬运内部发布教程、工单、生产日志、开发过程记录和仅对原部署生效的需求文档；后续新增社区版需求可单独维护。
5. 来源能力发生变化时，同时核对社区版源码、主题、终稿、路由和本地链接。删除或迁移主题须清理全部引用。
6. 发布前检查敏感字符串、地址类型、链接、机读 JSON、主题依赖和源码锚点。检测通过不能代替维护者审阅。

## 维护边界

本文档描述当前实现，不承诺任意模型的生成质量或外部服务可用性。离线测试、真实模型验收和部署环境验证分别记录，不能把历史环境的验证结果写成社区版保证。

沿用本仓库已初始化的 Flow2Spec 目录、通用路由与创作规则；业务知识以静态 Markdown/JSON 保存，不参与应用运行。根目录 `docs/` 面向使用者；这里面向代码阅读、维护与 Agent 上下文，两者相互链接并保持一致。
