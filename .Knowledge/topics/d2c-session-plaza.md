# 会话广场与个人作品

## 适用场景

公开会话、广场、发布撤回、访客在线编辑、保存为作品、再次编辑、个人副本、公开子 Agent。

## 核心规则

- 所有广场接口继承 D2C 登录要求，身份来自 本地登录账号；优先按会话记录的创建者授权；创建者为空（含历史空白）且工作区为个人归属（teamId 为 NULL 或空字符串）时，兼容由工作区拥有者公开或撤回。团队会话不使用该回退，已有明确创建者时也不回退；权限比较沿用账号规范化规则。没有匿名浏览接口。
- `D2cSessionShare` 单会话一条发布状态；公开范围为全部已登录用户。撤回后旧 shareId 不再有效，重新发布轮换 UUID；会话或工作区软删除后不再公开。
- `sharing/service.ts` 只投影公开元数据、时间线显示字段、已发送图片附件及产物；不返回 SDK 历史、检查点、凭据、工作区配置、内部文件或未发送的队列草稿。附件和文件链接改写为广场读取路径，子 Agent 记录按同一发布状态授权。
- 广场是只读源：没有发送消息、修改原文件或应用回原工作区的接口。访客在线编辑以当前产物创建独立副本，Redis 按用户、来源和编辑器命名空间隔离；每次访问重新校验源公开状态。
- 原工作区编辑、广场副本和个人作品副本使用不同 Redis 前缀、预览前缀与缓存目录。`plazaedit-`、`workedit-` 仍经过原 H5/RN 网关的短票据、CSP 和 iframe 隔离；编辑服务直接拒绝 detached apply，不依赖前端隐藏按钮。
- 临时保存只更新两小时 Redis 副本；“保存为作品”由服务端导出已验证副本，再写入 `D2cSavedWork` 与 `D2cSavedWorkFile`。不接受浏览器上传任意 owner 或快照替代可信副本，不使用默认全员可见的旧版本表保存个人副本。
- 个人作品所有读取、下载及覆盖保存均匹配当前用户；首次保存按用户/副本/修订幂等，再次编辑按作品修订冲突保护。作品文件按修订冻结，源码内容入库，图片保留不可变对象定位；保存副本不依赖源会话或原发布继续存在。
- “已保存作品”详情直接挂载本人副本的代码和预览区域，保存更新自己的作品，下载生成冻结文件 ZIP；不会替换原作者的工作区。预览只保存必要单位配置，不复制模型、密钥或 Figma 凭据。

## 入口与存储

`sharing/routes.ts` 提供 `/sessions/:id/sharing`、`/plaza/sessions`、`/my-works`；两种 detached edit 接口只有创建、读取、临时保存、删除、持久保存和下载。`sharing/runtime.ts` 延迟装配服务；`savedWork/service.ts` 管理永久快照。前端 `SessionSharing`、`CommunityPanel` 和 `EditWorkspace` 对应发布开关、广场/个人作品及独立编辑。

发布前执行 `.Knowledge/req-docs/d2c-session-plaza_迁移.sql` 新建三张表；仅注册模型，不自动迁移数据库。内部与公共仓库分别沿用自身身份、运行配置和对象存储，不混入另一仓库的平台依赖。

## 边界

撤回阻止新读取和临时副本访问，不能撤回此前下载或保存的个人作品。公开会话可展示其已保存对话与过程，发布者应在公开前确认内容适合共享。已保存作品保留编辑快照；会话分支则通过公开正文重建续聊上下文。

## 广场详情编辑布局与用量

- 广场详情创建访客隔离编辑副本，已保存作品详情创建本人作品副本；均直接展示左侧文件目录与 Monaco 代码、右侧运行预览，窄屏上下排列。保存并预览仅更新副本，保存为作品和下载沿用原授权边界。
- 对话默认隐藏，通过“查看对话”打开抽屉后才读取时间线，子 Agent 继续使用广场鉴权路径。打开对话或用量不重建编辑器，保留未保存源码；返回、切换及关闭页面保护尚未持久保存的改动。
- “用量”通过 GET /plaza/sessions/:id/usage 查询所有轮次的持久化用量与累计耗时，包含主模型、子模型及摘要，未报告值保持未知。接口只投影聚合值与观察时间，读取前后复查公开状态，不返回模型配置、上下文、检查点或私有诊断。
- 实现入口为 CommunityPanel、EditWorkspaceSurface 和 sharing/service.ts；回归见 plazaUsage、sharingFrontend、editWorkspaceUi 测试。

## 列表封面、导航与对话阅读

- 页面导航统一使用路径：工作台 /workbench、工作区 /workbench/:workspaceId、会话 /workbench/:workspaceId/sessions/:sessionId、版本列表 /works、版本详情 /works/versions/:versionId、已保存作品 /plaza/saved/:workId（集合 /plaza/saved，旧 /works/saved 路径兼容并替换为新路径）、广场 /plaza/:shareId（集合 /plaza）。导航以 pushState 保留历史，前进/后退恢复页面；未保存或操作进行中沿用退出保护。历史根路径与 slbhealthcheck.html 查询链接在入口解析后替换为规范路径，已有分享继续有效。接口参数与预览票据沿用各自协议。
- 顶栏固定提供工作台、作品库、广场三个入口；作品库仅展示会话版本，广场统一使用“全部作品 / 我发布的作品 / 已保存作品”单层分类。会话版本由工作台的“暂存版本”产生，已保存作品由详情编辑后点击“保存为作品”产生，沿用各自数据与权限；已保存作品详情归属广场主导航。空列表显示来源和操作说明。
- 广场卡片使用会话最早一张已持久化的真实运行截图作为封面，经现有广场附件鉴权读取；按页批量选择附件元数据。截图需符合运行截图消息、附件、摘要标识、尺寸和定位约束；无可用截图或加载失败显示占位。用户上传图片及设计基线图不作为封面。
- “查看对话”打开后串行读取历史，每页立即呈现并显示进度；关闭抽屉取消读取，失败保留已读取页并从失败游标重试。刷新重新读取。用户和助手正文均使用现有安全 Markdown 渲染；时间线取消装饰序号，正文中的有序列表仍正常显示。
- 广场、会话版本和已保存作品详情的返回按钮与实际项目名称同一行显示，右侧保留编辑、下载、刷新及对话操作；详情不额外重复通用列表标题。菜单切换和返回沿用编辑退出保护。
- 本次复用本地账号、标准存储及现有数据与接口，未新增配置或表迁移。实现见 CommunityPanel、communityHistory、main、WorksPanel 及 sharing/service；回归见 plazaCover、communityHistory、communityExperienceBrowser。

## 用量查询与时间线体积

- 用量读取已有 d2c_run.usage 和 d2c_timeline 的停止状态，不需要新增用量表。固定 JSON 路径使用静态 SQL 表达式，回归必须检查 Sequelize 生成的 SQL；fn 的字符串参数会将 $.status 转义为 $$.status，导致数据库拒绝 JSON 路径。通用“作品服务暂不可用”需要核对底层异常，不能直接判为缺表。
- 广场主对话在数据库投影阶段移除子 Agent 事件中的 message 和 reasoning 大字段，仅传入口、角色、状态及轻量过程信息；展开子 Agent 后，原独立事件接口仍按授权读取完整正文与思考。主对话正文、分页扫描游标及原始数据库记录保持。

- SQL 路径及大字段投影通过 plazaUsage、plazaTimelineProjection 和 sharing 回归验证，采用模拟数据与实际 SQL 生成检查。

## 作品库列表封面

- 会话版本卡片优先使用自身冻结文件中的首张有效 `design-reference/root-<节点编号>.png`，按节点编号稳定选择；缺失时选体积最大的有效 PNG/JPEG/WebP 图片资源，同大小按路径稳定选择，统一标注“作品图片”。无图、地址不安全或图片加载失败显示占位；卡片左侧文字、右侧图片；长图按原比例在固定高度的图片区域内滚动，封面可点击及键盘打开详情，图片懒加载，窄屏仍保持左右结构。
- 服务端在列表分页后批量查询本页冻结图片元数据，返回安全 `coverUrl` 或 null；封面选择不读取源码/正文引用、不下载图片、不构建预览。版本沿用已完成版本及团队筛选。
- 图片路径、路径摘要、图片格式、大小与内容摘要须匹配冻结定位；异常候选跳过。原始定位及配置保持私有。广场继续使用首张运行截图，版本作品图片只说明已保存的图片来源，不能作为运行或规则验收通过的证明。无需新增表、数据迁移或配置；仅更新服务与前端即可生效。
- 实现入口：`version/gallery.ts`、`savedWork/service.ts`、`utils/workCover.ts`、`WorkCover.tsx`；回归覆盖冻结来源、分页批量读取、账号/修订隔离、无图及坏图回退和真实浏览器的列表交互。


- 已保存作品与来源广场共用sharing/runtimeCover.ts选择最早真实运行截图；不从设计基线或大尺寸素材回退。保存时只从受信任来源读取并冻结无鉴权参数的runtimeCoverUrl到已有configSnapshot，编辑覆盖和个人作品复制保留该封面，预览配置及HTTP请求中的同名字段不作为可信封面输入。
- 历史作品缺少冻结封面时，按本页sourceId批量查询仍公开且会话/工作区存活的来源；读取后复查发布状态。来源失效、无法还原或无运行截图时显示占位；已有冻结封面不依赖原发布继续存在。列表先排序读取作品标识再回填JSON，保持账号隔离，不下载图片或启动编译。
- 无需新表、SQL迁移或配置。作品库会话版本仍使用原冻结作品图片规则；已保存作品与广场统一标注运行截图。回归见savedWork、plazaCover、libraryCover和communityExperienceBrowser。

## 广场卡片左右布局

- CommunityPanel的广场列表与个人作品统一复用library-works-grid/library-work-card：左侧标题、类型、作者与操作，右侧固定高度封面；窄屏仍保持左右结构，长图按原比例在图片区滚动。
- WorkCover的运行截图同样支持方向键、翻页键与Home/End滚动，Enter/点击沿用打开详情。广场仍取运行截图，作品库仍取冻结作品图片，安全地址、懒加载与无图/坏图占位沿用原逻辑。桌面与390px窄屏使用真实组件和隔离接口验证，不改变列表接口或存储。

## 保存记录删除

- 会话版本列表和详情按服务端 `canDelete` 展示删除入口，仅创建者可删除已就绪版本；个人作品列表和详情仅允许本人删除。点击后先确认，取消或关闭确认框不发删除请求，失败保留记录并可刷新。详情有未保存编辑时确认框说明一并丢弃，保存作品期间禁止删除。
- `DELETE /versions/:versionId` 与预览创建共用版本行锁，在短事务内移除该版本的冻结文件、预览登记及版本行。旧固定链接和票据随预览登记移除而失效，已下载内容或浏览器已加载画面无法追溯撤回。
- `DELETE /my-works/:id` 必填 `expectedRevision`，在本人作品行锁内核对当前修订并清理该作品所有冻结修订与作品行；旧列表遇到新修订返回409，刷新后由用户重新确认。再次编辑保存成功会刷新作品详情修订。
- 删除后列表重新加载，末页空缺时修正页码；详情删除成功后强制替换已失效的详情地址并返回列表，避免草稿离开保护重复拦截已确认的删除。服务端继承登录及同源保护，保留源会话、工作区、独立保存副本和共享对象存储；无需新增表、迁移或配置。真实工作台会话沿用原删除流程。
- 实现为 `version/gallery.ts`、`savedWork/service.ts`、`DeleteSavedItem`、`WorksPanel`、`CommunityPanel`；回归见 `libraryDelete`、`versionRoutes`、`sharingRoutes` 与 `libraryManagementBrowser`。

## 创建时间与操作展示

- 广场及已保存作品列表、详情展示服务端已有创建时间；按浏览器本地日历显示今天时分、近期星期、更早日期，原始时间保留在time属性和提示中。缺失或非法时间显示未知，不补造时间。
- 列表底部的查看及常用操作靠左，删除或下线靠右；下载和进入会话在卡片中使用带可访问名称及提示的图标按钮。详情按元数据、操作分行，来源会话、下载、复制靠左，删除靠右；窄屏不突破卡片。作品库顶部直接展示列表及筛选。
- 已保存作品详情展示真实编辑副本，不只展示元数据。详情元数据刷新失败时保留已挂载编辑内容并提供重试；未保存修改和保存进行中的导航保护继续生效。通用列表标题仅在列表渲染，详情保留单一返回按钮。
- 实现：CommunityPanel、WorksPanel、DeleteSavedItem、main、appRoutes；回归覆盖详情进入即显示源码、继续保存、未保存删除确认、旧路径迁移、导航离开保护与桌面/窄屏操作布局。

## 版本来源会话跳转

- 会话版本详情提供“查看来源会话”，定位取自版本保存的workspaceId/sessionId，仅在源会话仍存活、关联一致且当前用户具有工作区读权限时返回sourceSession；工作区拥有者与当前团队成员沿用原授权规则。
- 来源只查询会话定位与工作区授权字段；列表不返回私有会话定位。来源已删除、历史缺失或无权限时返回null，页面提示不可访问，冻结文件、下载和预览仍可独立读取。数据库故障保持真实错误。
- 普通点击沿现有导航进入/workbench/:workspaceId/sessions/:sessionId，前进/后退恢复页面；快捷键点击保留原生新标签页行为。身份继续使用本地登录账号，不新增表或配置。
- 实现：version/gallery.ts、WorksPanel、main；回归：versionSourceSession、libraryManagementBrowser及appRoutesBrowser。

## 固定在线预览链接复制

- 作品库会话版本详情右上角提供“复制预览链接”，复制当前所选入口已校验的长期预览票据，并补齐当前站点来源得到可直接打开的在线地址。
- 尚未取得长期链接、切换版本/入口或链接失效时禁用复制；重新取得有效链接后恢复。复制沿用已有票据，不创建编译任务，也不复制作品详情页地址。
- 复制成功与剪贴板失败分别使用App上下文的Ant Design message提示；复制失败保留真实预览和版本内容。入口由WorksPanel与PreviewPanel现有状态联动，无新增接口、配置或数据迁移。

## 我发布的作品管理

- 广场统一分类展示全部作品、我发布的作品和已保存作品；其中“我发布的作品”通过GET /plaza/sessions的scope=mine在数据库计数及分页前按真实发布管理归属过滤；仅展示仍公开且来源存活的条目，沿用历史个人工作区拥有者回退。缺省all保留原列表行为，非法scope返回422。
- 列表和详情的canManage及sourceSession由服务端核对当前私有工作区权限后投影；权限失效或关联变化时禁用管理及来源定位。进入会话沿用现有导航和草稿离开保护，修饰键保留原生新标签页行为。
- 下线使用带电源图标的轻描边按钮，默认低强调、悬停使用警示色，提供含义提示、键盘焦点和加载禁用态，卡片内保持靠右。下线复用PUT /sessions/:id/sharing及原身份、同源和归属校验；成功message提示并刷新当前分页，末页空缺回到前页；失败保留卡片并提示。下线使旧公开链接失效，冻结作品和源会话不删除。
- 实现为sharing/service.ts、sharing/routes.ts、CommunityPanel及PublishedSessionActions；无需新增表、数据迁移或配置。

## 分类导航与作品命名

- 集合页用一条轻量下划线导航切换全部作品、我发布的作品及已保存作品，数量和刷新并排展示，详情沿用返回入口；移除外层重复分类按钮与集合标题。主入口保留跨分类的发布范围，切换仍经过已有草稿/保存中离开保护。
- 点击“保存为作品”先显示Ant Design命名弹窗；首次默认来源广场作品名加浏览器本地短日期（如首页活动 · 1123），已有作品再次编辑保留原名。默认名为日期后缀预留长度，输入trim后须为1–200字符；用户可修改名称。
- 确认命名后才沿原save接口传name，取消不发送保存请求，失败保留名称及弹窗供重试，保存期间禁止重复提交和关闭；原保存回调、修订及草稿保护保持。来源名由CommunityPanel传入EditWorkspaceSurface，不新增接口或表。

## 从广场创建会话分支

- 广场详情提供“创建分支并继续”，选择本人就绪的个人工作区和本人 Figma 凭据，命名后进入工作台的空闲新会话；创建不调用模型，之后用户发送新消息才执行。未保存编辑或保存中先处理当前副本。
- POST /plaza/sessions/:shareId/forks 只接受workspaceId、credentialId、UUIDv4 clientRequestId和可选name；登录身份取自服务端，同源与私有响应保护沿用。相同用户、来源、工作区和请求标识得到同一UUIDv5会话并满足Agent检查点契约；事务内复核来源公开、文件修订及目标归属，来源变化返回冲突，失败整体回滚。
