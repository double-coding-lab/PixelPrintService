# 会话广场与个人作品

## 适用场景

公开会话、广场、发布撤回、访客在线编辑、保存为作品、再次编辑、个人副本、公开子 Agent。

## 核心规则

- 所有广场接口继承 D2C 登录要求，身份来自 本地登录账号；优先按会话记录的创建者授权；创建者为空（含历史空白）且工作区为个人归属（teamId 为 NULL 或空字符串）时，兼容由工作区拥有者公开或撤回。团队会话不使用该回退，已有明确创建者时也不回退；权限比较沿用账号规范化规则。没有匿名浏览接口。
- `D2cSessionShare` 单会话一条发布状态；公开范围为全部已登录用户。撤回后旧 shareId 不再有效，重新发布轮换 UUID；会话或工作区软删除后不再公开。
- `sharing/service.ts` 只投影公开元数据、时间线显示字段、已发送图片附件及产物；不返回 SDK 历史、检查点、凭据、工作区配置、内部文件或未发送的队列草稿。附件和文件链接改写为广场读取路径，子 Agent 记录按同一发布状态授权。
- 广场是只读源：没有发送消息、修改原文件或应用回原工作区的接口。访客在线编辑以当前产物创建独立副本，Redis 按用户、来源和编辑器命名空间隔离；每次访问重新校验源公开状态。
- 原工作区编辑、广场副本和个人作品副本使用不同 Redis 前缀、预览前缀与缓存目录。`plazaedit-`、`workedit-` 仍经过原 H5/RN 网关的短票据、CSP 和 iframe 隔离；编辑服务直接拒绝 detached apply，不依赖前端隐藏按钮。
- 临时保存只更新两小时 Redis 副本；“保存为作品”由服务端导出已验证副本，再写入 `D2cSavedWork` 与 `D2cSavedWorkFile`。不接受浏览器上传任意 owner 或快照替代可信副本，不使用默认全员可见的旧版本表保存个人副本。
- 个人作品所有读取、下载及覆盖保存均匹配当前用户；首次保存按用户/副本/修订幂等，再次编辑按作品修订冲突保护。作品文件按修订冻结，源码内容入库，图片保留不可变对象定位；保存副本不依赖源会话或原发布继续存在。
- “已保存作品”允许再次编辑自己的已保存副本，保存更新自己的作品，下载生成冻结文件 ZIP；不会替换原作者的工作区。预览只保存必要单位配置，不复制模型、密钥或 Figma 凭据。

## 入口与存储

`sharing/routes.ts` 提供 `/sessions/:id/sharing`、`/plaza/sessions`、`/my-works`；两种 detached edit 接口只有创建、读取、临时保存、删除、持久保存和下载。`sharing/runtime.ts` 延迟装配服务；`savedWork/service.ts` 管理永久快照。前端 `SessionSharing`、`CommunityPanel` 和 `EditWorkspace` 对应发布开关、广场/个人作品及独立编辑。

发布前执行 `.Knowledge/req-docs/d2c-session-plaza_迁移.sql` 新建三张表；仅注册模型，不自动迁移数据库。内部与公共仓库分别沿用自身身份、运行配置和对象存储，不混入另一仓库的平台依赖。

## 边界

撤回阻止新读取和临时副本访问，不能撤回此前下载或保存的个人作品。公开会话可展示其已保存对话与过程，发布者应在公开前确认内容适合共享。个人作品不复制模型上下文，不产生新的 Agent 会话。

## 广场详情编辑布局与用量

- 详情默认直接创建访客隔离编辑副本，左侧文件目录与 Monaco 代码、右侧运行预览；窄屏上下排列。保存并预览仅更新副本，保存为作品和下载沿用原授权边界。
- 对话默认隐藏，通过“查看对话”打开抽屉后才读取时间线，子 Agent 继续使用广场鉴权路径。打开对话或用量不重建编辑器，保留未保存源码；返回、切换及关闭页面保护尚未持久保存的改动。
- “用量”通过 GET /plaza/sessions/:id/usage 查询所有轮次的持久化用量与累计耗时，包含主模型、子模型及摘要，未报告值保持未知。接口只投影聚合值与观察时间，读取前后复查公开状态，不返回模型配置、上下文、检查点或私有诊断。
- 实现入口为 CommunityPanel、EditWorkspaceSurface 和 sharing/service.ts；回归见 plazaUsage、sharingFrontend、editWorkspaceUi 测试。

## 列表封面、导航与对话阅读

- 页面导航统一使用路径：工作台 /workbench、工作区 /workbench/:workspaceId、会话 /workbench/:workspaceId/sessions/:sessionId、版本列表 /works、版本详情 /works/versions/:versionId、已保存作品 /works/saved/:workId（集合 /works/saved）、广场 /plaza/:shareId（集合 /plaza）。导航以 pushState 保留历史，前进/后退恢复页面；未保存或操作进行中沿用退出保护。历史根路径与 slbhealthcheck.html 查询链接在入口解析后替换为规范路径，已有分享继续有效。接口参数与预览票据沿用各自协议。
- 顶栏固定提供工作台、作品库、广场三个入口；作品库下分“会话版本”和“已保存作品”。会话版本由工作台的“暂存版本”产生，已保存作品由详情编辑后点击“保存为作品”产生，沿用各自数据与权限。空列表显示来源和操作说明。
- 广场卡片使用会话最早一张已持久化的真实运行截图作为封面，经现有广场附件鉴权读取；按页批量选择附件元数据。截图需符合运行截图消息、附件、摘要标识、尺寸和定位约束；无可用截图或加载失败显示占位。用户上传图片及设计基线图不作为封面。
- “查看对话”打开后串行读取历史，每页立即呈现并显示进度；关闭抽屉取消读取，失败保留已读取页并从失败游标重试。刷新重新读取。用户和助手正文均使用现有安全 Markdown 渲染；时间线取消装饰序号，正文中的有序列表仍正常显示。
- 广场、会话版本和已保存作品详情的返回入口置于标题区左侧；右侧保留编辑、下载、刷新及对话操作。菜单切换和返回沿用编辑退出保护。
- 本次复用本地账号、标准存储及现有数据与接口，未新增配置或表迁移。实现见 CommunityPanel、communityHistory、main、WorksPanel 及 sharing/service；回归见 plazaCover、communityHistory、communityExperienceBrowser。
