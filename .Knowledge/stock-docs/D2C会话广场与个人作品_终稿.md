# D2C 会话广场与个人作品

## 用户流程

1. 会话创建者点击“发布到广场”，共享聊天、工具过程、子 Agent 记录和产物。未记录创建者的旧会话若属于个人工作区，工作区拥有者也可发布和撤回；团队会话不回退授权。
2. 从顶栏“广场”选择会话，查看公开聊天与源码资源；查看者不能发送消息或改变原工作区。
3. 点击“在线编辑”从当前产物创建本人的临时副本，保存源码后更新副本预览。
4. 点击“保存为作品”将当前副本长期保存。临时编辑和长期作品是两种保存状态。
5. 从广场中的“已保存作品”打开自己的作品，直接展示代码与预览，保存只更新自己的作品；也可下载 ZIP。
6. 原作者撤回公开后广场访问失效，但其他人此前保存的个人作品仍保留。

## 数据与权限

| 内容 | 存储位置 | 生命周期与归属 |
| --- | --- | --- |
| 发布状态 | MySQL `d2c_session_share` | 一会话一条；创建者管理，历史个人会话兼容工作区拥有者 |
| 临时编辑 | Redis 独立命名空间 | 用户与来源隔离，两小时到期 |
| 个人作品信息 | MySQL `d2c_saved_work` | 本人长期保存，修订控制 |
| 个人作品源码与资源清单 | MySQL `d2c_saved_work_file` | 按作品修订冻结，图片引用不可变对象 |
| 预览构建产物 | 本地 preview cache | 短票据，通过 H5/RN 同源预览网关读取 |
| 图片原始内容 | 现有对象存储 | 校验大小与摘要，源码不会保存上传凭据 |

## 开发与部署

- 业务契约和实现边界见 [会话广场主题](../topics/d2c-session-plaza.md)。
- 接口在 `src/functions/d2c/sharing/routes.ts`；公开读取服务在 `sharing/service.ts`，独立编辑接线在 `sharing/runtime.ts`，个人作品在 `savedWork/service.ts`。
- 发布前审核执行 [新增三表 SQL](../req-docs/d2c-session-plaza_迁移.sql)。SQL 不更改原会话与工作区表，不自动公开历史数据。
- 未登录不允许访问；团队成员可共同开发，但不能替会话创建者公开；历史个人会话回退仅影响发布管理，不回填创建者身份。个人作品与原有暂存版本作品列表是不同的数据集合。
- 撤回、归属和修订冲突均由服务端检查；前端没有应用回原工作区的入口，编辑服务也直接拒绝此操作。

## 验证记录

自动化验证及部署待办见 `.task/taolan/active/session_plaza/acceptance.md`。真实数据库建表与浏览器双账号联调需在部署后完成。

广场详情默认左侧代码、右侧预览，直接编辑访客副本；对话和聚合用量按需打开。退出保护与接口投影见[详情布局与用量](../topics/d2c-session-plaza.md#广场详情编辑布局与用量)。

顶栏提供工作台、作品库、广场；作品库展示会话版本，广场提供“广场作品”和“已保存作品”两个入口。广场使用首张运行截图封面，对话支持 Markdown 与自动补读。页面采用路径导航并支持前后退，旧查询链接继续兼容，见[列表封面与导航](../topics/d2c-session-plaza.md#列表封面导航与对话阅读)。

主对话仅加载子 Agent 入口摘要，详情在展开子任务后读取；用量依赖已有执行与时间线表，固定 JSON 路径须验证实际 SQL。见[用量与时间线体积](../topics/d2c-session-plaza.md#用量查询与时间线体积)。

## 作品库封面


广场卡片复用作品库的左文右图布局，运行截图长图同样支持栏内滚动和键盘操作，窄屏保持左右排列；广场仍使用真实运行截图来源，详见[广场卡片左右布局](../topics/d2c-session-plaza.md#广场卡片左右布局)。

会话版本与已保存作品优先使用自身冻结的整页设计图，缺失时采用最大的有效图片资源作封面，标明“作品图片”，缺图或加载失败显示占位。列表采用左侧文字、右侧图片，长图在图片区域按原比例滚动。元数据按页批量读取并保持账号、版本和修订边界；具体来源及验证约定见[作品库列表封面](../topics/d2c-session-plaza.md#作品库列表封面)。

会话版本与已保存作品的列表、详情提供本人记录删除，先确认并核对归属与作品修订；末页删除修正页码，删除对应预览登记后旧链接失效。源会话及独立副本保留，无需迁移或新配置。见[保存记录删除](../topics/d2c-session-plaza.md#保存记录删除)。

广场与保存作品展示创建时间，列表操作居中，查看和下载采用统一按钮，删除收敛为灰色图标并保留确认；旧保存作品地址自动转换为广场路径，草稿和保存中的退出保护继续生效。详见[创建时间与操作展示](../topics/d2c-session-plaza.md#创建时间与操作展示)。

作品库固定预览通过详情右上角“复制预览链接”复制当前入口的长期在线地址；等待、切换或失效期间禁用，复用已有票据且不触发编译。详见[固定在线预览链接复制](../topics/d2c-session-plaza.md#固定在线预览链接复制)。
