需要自己提供模型吗？+

在线工作台由每位用户配置自己的模型地址、模型名称与 API Key，生成前还需配置个人 Figma Token。模型接口需要支持工具调用。

可以部署在自己的服务器上吗？+

可以。开源服务版提供单机部署方案，也能对接已有的 MySQL、Redis 和 S3 兼容对象存储。具体兼容范围与操作步骤见仓库部署文档。

生成后还可以继续修改吗？+

可以通过对话继续调整页面，也能查看和编辑源码、编译预览、保存版本或下载代码。视觉与交互效果仍需结合实际页面验收。
