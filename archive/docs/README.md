# 文档归档

使用者入口已统一到 [docs](../../docs/README.md)。本目录保留源码阅读、工具联调、内部实现及历史迁移材料，不作为日常操作指南。

- `technical/`：原技术说明和维护参考。内容保留，适用范围按各自核对日期理解；当前规则以[知识库](../../.Knowledge/index.md)和实际部署为准。
- `history/`：历史问题、迁移基线、选型和验收记录；其中的旧路径、结果和待办不是当前能力承诺。

归档只调整阅读位置，不删除用户数据或停用产品功能。内部资料仅在内部仓库保留，公共版文档不复制内部记录。
